# 🌹 ASCII Rose & Love Letter Envelope (Videodagi kabi sahifa)

Ushbu loyiha videodagi mashhur **ASCII Rose & Envelope** (gullaydigan atirgul va konvert) sahifasining to'liq va takomillashtirilgan ko'rinishidir.

---

### ✨ Imkoniyatlar va Xususiyatlar:
1. **To'liq ASCII Animatsiyasi**:
   - Dastlab yopiq konvert, o'rtasida urib turuvchi qizil neon yurakcha (`♥`).
   - `[ for you ]` (yoki siz kiritgan maxsus ism) yozuvi.
   - Retro pikselli kursorni avtomatik harakati yoki sichqoncha/sensor orqali bosish.
   - Konvert ochilishi (flap origami animatsiyasi).
   - Qizil atirgulning unib chiqishi, yam-yashil poya va barglar, hamda qatlam-qatlam qizil yaproqlarning ochilishi.
   - Atirgul atrofidagi porlovchi yulduzlar (radiating sparkle crosses) va havoga ko'tariluvchi yurakchalar.
2. **Asl Musiqa va Ovoz**:
   - Videodagi mashhur musiqa (`love_me.m4a`) va Web Audio API orqali sintez qilingan sehrli ohanglar.
   - Musiqani yoqish/o'chirish tugmasi.
3. **Shaxsiylashtirish (Personalization)**:
   - "Xabarni sozlash" tugmasi orqali istalgan ism va tabrik xabarini yozish mumkin.
   - Havolani ulashish (Share): Yaratilgan xabar maxsus link orqali boshqalarga yuborilishi mumkin (masalan, Telegram, WhatsApp orqali).
4. **Rang Mavzulari (Themes)**:
   - 🌹 Klassik Atirgul (videodagi asl qizil/yashil ranglar)
   - 🌌 Kiberpank Neon (binafsharang / moviy kiber-uslub)
   - ✨ Oltin Quyosh (oltin / amber uslubi)
5. **Matnni Nusxalash**:
   - Atirgul ASCII kodini to'g'ridan-to'g'ri nusxalab, Telegram yoki boshqa messenjerlarda jo'natish tugmasi.

---

### 🚀 Qanday ishga tushirish mumkin:

#### 1-usul: To'g'ridan-to'g'ri brauzerda ochish
Loyihadagi `index.html` faylini istalgan brauzerda (Google Chrome, Microsoft Edge, Safari) ikki marta bosib oching.

#### 2-usul: Python orqali mahalliy serverda ochish
Terminalda quyidagi buyruqni bering:
```bash
python run_app.py
```
Bu avtomatik ravishda `http://localhost:3000/` manzilini brauzeringizda ochadi.
